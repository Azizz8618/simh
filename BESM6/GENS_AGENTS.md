# GENS_AGENTS.md — Навык работы с генератором системы ГЕНС (ОС Диспак)

## 1. Назначение

Этот навык описывает процедуры работы с генератором системы ГЕНС для ОС Диспак и смены конфигураций при отладке эмулятора БЭСМ-6.

**Целевая аудитория:** ИИ-агенты, работающие над отладкой эмулятора БЭСМ-6.

---

## 2. Общие сведения о ГЕНС

### 2.1. Что такое ГЕНС?

ГЕНС (Генератор Системы) — программа ОС Диспак, которая создаёт индивидуальную конфигурацию системы под конкретное оборудование и задачи пользователя.

### 2.2. Расположение файлов

| Путь | Содержимое |
|------|------------|
| `~/Yandex.Disk/re_dispak/re-dispak/gens/` | Примеры конфигураций (.b6 файлы) |
| `~/Yandex.Disk/simh/BESM6/dispak.ini` | INI-файл эмулятора |

**Файлы конфигураций:**
- `gens.b6` — базовая (VT:1-10, АС,ТТ:11-16)
- `gens_exp.b6` — экспериментальная (VT:1-2, АС,VT:3-16)
- `gens_rab.b6` — рабочая (VT:1-30, АС,ТТ:3-10)
- `gens_test.b6` — тестовая (минимум)
- `1`–`9` — примеры с результатами работы ГЕНС

## 3. Формат файла конфигурации (.b6)

### 3.1. Структура файла

```
ШИФР <код>‾ОЗУ <объём>‾ВХО <входы>‾ВРЕ <время>‾РОС <режим>‾Е
B63
<загрузочные команды K и константы C>
B100A1
<директивы конфигурации>
ЕКОНЕЦ
```

### 3.2. Синтаксис директив

**Формат:** `ДИРЕКТИВА <параметры>^`

Все директивы оканчиваются символом `^` (крышка).

## 5. Секция "ИНФОРМАЦИЯ К ГЕНСУ"

После директив идёт секция с 16-ричными данными (адреса 72000-72037):

```
ИНФОРМАЦИЯ К ГЕНСУ

72000
 0000056000004005    # Конфигурационное слово 0
 ...
72010
 0000000000000022    # Маски MGRP/MPRP
 ...
```

| Адрес | Назначение |
|-------|------------|
| 72000-72007 | Конфигурация терминалов |
| 72010-72017 | Маски прерываний |
| 72020-72037 | Параметры системы |

## 6. Соответствие конфигурации ГЕНС и эмулятора

**Важно:** Эмулятор НЕ читает файлы .b6 напрямую! Конфигурация загружается через образ диска.

### 6.1. Таблица соответствия

| ГЕНС | Эмулятор (команда) |
|------|-------------------|
| `ТТ 1^` | `SET tty1 tt` |
| `ТЕРМ VT:1-10^` | `SET ttyN vt` для N=1..10 |
| `ТЕРМ АС,ТТ:11-16^` | `SET ttyN tt` + `SET ttyN mux` |
| `ТЕРМ АС,VT:3-47^` | `SET ttyN vt` + `SET ttyN mux` |
| ДКС (СВЯЗЬ7) | `SET ttyN dks` |

### 6.2. Пример: синхронизация gens_rab.b6

**ГЕНС:**
```
ТТ    1^
ТЕРМ  VT:1-30^
ТЕРМ  АС,ТТ:3-10^
ТЕРМ  ТТ:11-16^
```

**INI-файл:**
```ini
; Главный терминал ТТ:1
SET tty1 tt
ATTACH tty1 4001

; VT:1-30
SET tty2 vt
ATTACH tty2 4002
... (tty3..tty30)

; АС,ТТ:3-10 (МУКС)
SET tty3 tt
SET tty3 mux
ATTACH tty3 4003
... (tty4..tty10)

; ТТ:11-16
SET tty11 tt
ATTACH tty11 4011
... (tty12..tty16)
```

## 7. Процедура смены конфигурации

### 7.1. Выбор существующей конфигурации

```bash
# Список конфигураций
ls -la ~/Yandex.Disk/re_dispak/re-dispak/gens/*.b6

# Просмотр терминалов
grep "ТЕРМ\|^ТТ" ~/Yandex.Disk/re_dispak/re-dispak/gens/gens.b6
```

### 7.2. Создание новой конфигурации

```bash
# Копирование шаблона
cp ~/Yandex.Disk/re_dispak/re-dispak/gens/gens.b6 \
   ~/Yandex.Disk/re_dispak/re-dispak/gens/gens_custom.b6

# Редактирование
nano ~/Yandex.Disk/re_dispak/re-dispak/gens/gens_custom.b6
```

**Проверка синтаксиса:**
- Все директивы оканчиваются на `^`
- Названия — заглавными буквами
- Параметры разделены запятыми

## 8. Сценарии отладки

### 8.1. Минимальная конфигурация

**ГЕНС:**
```
ТТ    1^
ТЕРМ  VT:1^
```

**INI:**
```ini
SET tty1 tt
ATTACH tty1 console
SET tty2 vt
ATTACH tty2 4002
```

**Применение:** Быстрая проверка загрузки системы.

### 8.2. Отладка ДКС

**Требования:**
- Модуль СВЯЗЬ7 на диске 2053 (зона 0677)
- В ГЕНС явно не указывается

**INI:**
```ini
SET tty3 vt
SET tty3 dks
ATTACH tty3 4003
```

**Проверка:**
```bash
./BIN/besm6 dispak.ini
telnet localhost 4003
```

### 8.3. Отладка МУКС

**ГЕНС:** `ТЕРМ АС,VT:3-16^`

**INI:**
```ini
SET tty3 vt
SET tty3 mux
ATTACH tty3 4003
...
```

## 9. Диагностика проблем

### 9.1. Система не загружается

| Проверка | Команда/Действие |
|----------|------------------|
| Диск соответствует ГЕНС | Образ диска должен быть сгенерирован |
| Объём ОЗУ | `grep "ОЗУ" gens.b6` |
| Синтаксис директив | Все `^` на месте |

### 9.2. Терминалы не работают

| Симптом | Причина | Решение |
|---------|---------|---------|
| Нет приглашения | Несоответствие конфигурации | Проверить ГЕНС vs INI |
| Нет эха | Неправильный тип (TT vs VT) | `SET ttyN tt/vt` |
| Зависание | ДКС без СВЯЗЬ7 | Проверить зону 0677 |

### 9.3. ДКС не реагирует

**Чек-лист:**
1. `SET ttyN dks` в INI
2. `ATTACH ttyN <порт>` в INI
3. СВЯЗЬ7 загружен (зона 0677 на диске)
4. Маски прерываний (секция 72010)

## 12. Критические замечания

1. **Эмулятор НЕ читает .b6 файлы** — конфигурация зашита в образ диска
2. **Изменение ГЕНС требует перегенерации системы** — нельзя просто отредактировать .b6
3. **СВЯЗЬ7 обязателен для ДКС** — без него ДКС не работает
4. **Номера линий должны совпадать** — ГЕНС и эмулятор используют одни и те же номера
5. **Маски прерываний важны** — секция 72010 настраивает MGRP/MPRP

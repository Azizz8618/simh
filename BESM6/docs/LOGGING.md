# Журналирование по подсистемам (per-subsystem logging)

## Общие сведения

Вместо монолитного файла `debug.txt` эмулятор записывает сообщения отладки
в отдельные файлы по подсистемам: `logs/debug_sys.log`, `logs/debug_cpu.log`,
`logs/debug_dks.log`, `logs/debug_mmu.log`, `logs/debug_disk.log`,
`logs/debug_vu.log`, `logs/debug_prn.log`, `logs/debug_punch.log`,
`logs/debug_pl.log`, `logs/debug_tty.log`.

Все ошибки также попадают в `logs/errors.log`.

## Файлы подсистем

| Подсистема | Имя файла       | Описание                          |
|-----------|----------------|-----------------------------------|
| `SYS`     | `debug_sys.log` | Системные события                  |
| `CPU`     | `debug_cpu.log` | Команды процессора, регистры       |
| `DKS`     | `debug_dks.log` | КАДОПАМ, терминалы, ПРП, прерывания|
| `MMU`     | `debug_mmu.log` | Модуль управления памятью          |
| `DISK`    | `debug_disk.log`| Операции с дисками                 |
| `VU`      | `debug_vu.log`  | Перфокарточное устройство          |
| `PRN`     | `debug_prn.log` | Принтер АЦПУ                       |
| `PUNCH`   | `debug_punch.log`| Перфолента (ФС1500)               |
| `PL`      | `debug_pl.log`  | ПЛ-80 (перфокарточный)             |
| `TTY`     | `debug_tty.log` | Терминалы (VT, TT, CONSUL, MUX)    |
| `ERRORS`  | `errors.log`    | Собранные ошибки всех подсистем    |

## Конфигурация в .ini-файле

В файл `dispak.ini` или другой конфигурационный файл эмулятора
добавляются следующие параметры (необязательные — если не указаны,
используются значения по умолчанию: `logs/`, 10 МБ):

```ini
; === Настройка per-subsystem журналирования ===

; Включение/отключение журналирования (по умолчанию: ON)
set cpu log=on      ; включить (log файлы в logs/debug_*.log)
; set cpu log=off   ; отключить (log файлы НЕ создаются)

; Каталог для файлов подсистемных логов (по умолчанию: logs/)
set cpu log-dir=logs

; Максимальный размер каждого файла подсистемы (в МБ)
; При превышении файла он автоматически сжимается (ротация)
; По умолчанию: 10 МБ. 0 = без ограничения
set cpu log-max=10
```

Если не добавлять никаких строк в `.ini`, журналирование
функционирует автоматически при запуске эмулятора
(файлы создаются в `logs/`).

## Уровни логирования

| Уровень  | Описание                        | Макрос                 |
|---------|--------------------------------|------------------------|
| `ERROR` | Ошибки (пишутся в errors.log)  | `BESM6_*_ERROR()`      |
| `WARN`  | Предупреждения                 | `b6_log(..., B6_LOG_WARN)` |
| `INFO`  | Информационные сообщения       | `b6_log(..., B6_LOG_INFO)` |
| `DEBUG` | Отладочные сообщения           | `BESM6_*_DEBUG()`       |
| `TRACE` | Детальная трассировка          | `b6_log(..., B6_LOG_TRACE)` |

## Примеры использования

### Просмотр логов ДКС

```bash
tail -f logs/debug_dks.log
```

### Просмотр всех ошибок

```bash
cat logs/errors.log
```

### Поиск событий регистрации терминалов

```bash
grep 'terminal.*registered' logs/debug_dks.log
```

### Очистка логов перед прогоном

```bash
rm -rf logs/
```

## Добавление нового вызова логирования

```c
/* Через макрос (рекомендуется) */
BESM6_DKS_DEBUG(">>> DKS: terminal %d registered", num);
BESM6_CPU_ERROR("UHV %o: address %o", addr);

/* Через функцию */
besm6_debug_sub(B6_LOG_DKS, ">>> KDP: PRP=%06o", PRP);
```

## Известные ограничения

- Фильтрация по уровням пока не реализована (все сообщения пишутся).
- Ротация происходит только при записи.
- Не поддерживается динамическое изменение максимального размера.

## Отключение журналирования

Для отключения пер-subsystemного журналирования (сообщения в `logs/*.log`):

```bash
# Включить журналирование (по умолчанию включено)
set cpu log=on

# Отключить журналирование (debug.txt продолжает работать)
set cpu log=off

# Проверить текущее состояние
show cpu log
```

При отключении:
- Сообщения пер-subsystemного журналирования НЕ пишутся в `logs/*.log`
- `debug.txt` (backward compatibility) продолжает работать
- Ошибки НЕ пишутся в `errors.log`
- Каталог `logs/` остаётся на месте (файлы не удаляются)

Для полного отключения журналирования:
1. `set cpu log=off` — отключить пер-subsystemные логи
2. `set console debug=off` — отключить `debug.txt`

Для очистки всех логов:
```bash
rm -rf logs/
```

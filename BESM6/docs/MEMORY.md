## Текущий статус (обновлено 2026-09-16)

### ✅ Сделано

- Прерывания ПРП5-8,12 генерируются в kadopam_svc()
- dks_register(), dks_poll() реализованы в besm6_tty.c
- telnet-подключение DKS-линии (tty11, порт 4203) — работает
- Привязка tmxr-линий к портам (LINE=N) — УСПЕХ (2026-09-15)
- Имитация слова РКС (слркс0) — работает

### ❌ Нерешённая проблема: MPRP=0 (chicken-and-egg)
ОС не вызывает УСТРП → MPRP=0 → ДКС-прерывания не доставляются → СВЯЗЬ7 не загружается.

### Стратегии решения
- **А (оставлена):** Push первого прерывания в sim_instr main loop
- **Б:** Эмуляция «пультового старта» СВЯЗЬ7
- **В:** Вызов УСТРП из init/boot
- **Г:** Модификация ОС (hardcode MPRP)
- **А+Г:** Комбинация (текущий план)

## Находки

### 2026-09-12 (адреса теста контактов ДКС)
- Тест пишет во ВСЕ адреса ОЗУ ДКС (10₈–67777₈)
- Т2 — единственный подтест, проходящ весь диапазон
- Команда Z13 → write_032() → kadopam_mem[addr]

### 2026-09-15 (привязка tmxr-линий)
- Корневая причина: tty_attach() не передавала LINE=N
- Исправление: snprintf LINE=N перед tmxr_attach
- Результат: PRP=005540, DKS-символы принимаются
- Проблема: MPRP=000000 throughout

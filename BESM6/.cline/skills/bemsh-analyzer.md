# Навык анализа листингов МАКРО-БЕМШ

## Правила анализа

### 1. Структура листинга
Листинг представляет собой таблицу:
- ОШИБКИ — количество ошибок трансляции
- НПК — номер перфокарты
- СВОБ — служебное поле размещения
- ПЕРЕМ — информация о перемещении (настройке)
- АДРЕС — адрес размещения (восьмеричный)
- КОМАНДА — содержимое ячейки
- А ИСП — исполнительный адрес
- N ГЕН — номер строки в генерируемом листинге
- N ИСХ — номер строки в исходном файле
- МЕТКА — определённая метка
- ОПЕРАЦИЯ — мнемоника команды
- ОПЕРАНД — операнд(ы)
- КОММЕНТАРИЙ — текст комментария

### 2. Специальные обозначения
- `*` — строка комментария, кода не порождает
- `_` — строка не генерирует код (директива, метка без команды)
- `‾` — адрес загрузки модуля или начала сегмента
- `+` в ПЕРЕМ — положительное перемещение для внешнего символа

### 3. Правила чтения
- Для связи с исходным текстом использовать N ИСХ
- Поле АДРЕС даёт фактическое размещение в памяти
- Код команды читается в восьмеричной системе
- Пример: `00 24 02003` = УИА с адресом 02003

### 4. Форматирование вывода
- Таблицы моноширинным шрифтом
- Ширина строки <= 60 символов
- Выравнивание всех столбцов
- Минимальный межстрочный интервал

### 5. Извлечение информации
При анализе листинга извлекать:
- Адрес загрузки модуля (первый адрес с ‾)
- Таблицу символов (метки и их адреса)
- Внешние ссылки (символы с + в ПЕРЕМ)
- Точки входа (метки, на которые есть переходы)

## Пример анализа

```
Вход: Листинг модуля ДИСП70

Анализ:
- Адрес загрузки: 00770 (‾ в поле АДРЕС)
- Размер модуля: 1577₈ слов
- Внешние символы: ВЗУ, КАЧКА, ВИСП
- Экспортируемые символы: ДИСП, Э20, Э21

Таблица точек входа:
+--------+--------+------------------+
| Метка  | Адрес  | Назначение       |
+--------+--------+------------------+
| ДИСП   | 00100  | Точка входа      |
| Э20    | 00250  | Экстракод 20     |
| Э21    | 00300  | Экстракод 21     |
+--------+--------+------------------+
```

## Экономия токенов

- Не перечитывать листинг полностью при повторных запросах
- Использовать извлечённую таблицу символов
- Кэшировать результаты анализа
- Отвечать кратко и по существу

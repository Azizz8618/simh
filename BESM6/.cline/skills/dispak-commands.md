# Стандартные команды для проекта ДИСПАК

## Команды пользователя

### «ПРОКОММЕНТИРУЙ ФАЙЛ»
**Значение:**
1. Открыть файл
2. Произвести подробный комментарий каждой процедуры
3. Записать комментарии в файл
4. Закрыть файл
5. Выполнить `make`
6. Удостовериться в отсутствии ошибок (все зоны должны совпадать с эталоном — "matches")
7. В случае ошибок — исправить их

**Важно:** Комментировать отрывками по 120 строк, заменять и проверять на правильность.

### «ОБЪЯСНИ [ПРОЦЕДУРУ/КОМАНДУ]»
**Значение:**
1. Проанализировать все процедуры и задействованных модулей ОС
2. Составить развёрнутое описание с блок-схемой в формате текстового комментария

### «ПРОАНАЛИЗИРУЙ ТРАССУ»
**Значение:**
1. Разбор логики, значений регистров, адресов и переходов
2. Работать с файлами трассировки типа `tr[n].txt`

### «ИСПРАВЬ [КОММЕНТАРИЙ/УЧАСТОК]»
**Значение:**
1. Внесение исправлений
2. Отладка программы при помощи пакетного эмулятора ОС ДИСПАК
3. Эмулятор вызывается командой `dispak`
4. Образцы тестовых программ в папке `~/dispak/tests/`

### «ВЫДАЙ ФРАГМЕНТ ЗАНОВО»
**Значение:**
Повтор ранее выданного текста с учётом последних правок.

### «СЛЕДУЮЩИЕ [N] СТРОК»
**Значение:**
Продолжение комментирования с указанного места.

### «ПОКАЖИ [СПРАВОЧНЫЙ МАТЕРИАЛ]»
**Значение:**
Выдача извлечений из RUKAVA, RUKAV1, RUKDKS.

## Правила выполнения

### Для комментирования
1. Соблюдать синтаксис комментариев:
   - БЕМШ: запятая ","
   - МАДЛЕН: точка "."
2. Длина строки комментария не более 55 символов
3. Перенос со звёздочкой "*"
4. Использовать таблицы моноширинным шрифтом, ширина <= 60 символов
5. Выравнивать все столбцы, минимальный интервал

### Для анализа
1. Всегда сверяться с текстами модулей ОС
2. Не домысливать при дефиците информации
3. Выводы сопровождать примерами из текстов
4. Указывать применяемые индекс-регистры

### Для исправлений
1. Проверять через `make`
2. Сравнивать зоны с эталоном через `cmpdsk.pl`
3. При ошибках — анализировать листинги (.lst)

| `rvs.pl` | Обработка раскроя ВС |
| `trace.pl` | Анализ трасс |
| `cmpdsk.pl` | Сравнение дисков |
| `zongp.pl` | Запись модуля в зону |
| `touched.pl` | Подготовка трасс |
| `mktest.pl` | Создание тестовых образов |

## Эмуляция

```bash
# Запуск задачи
dispak [опции] <файл.b6>

# Ключевые опции
-x, --native    # нативный экстракод E64
-e, --elfun     # нативные элементарные функции
-b, --break     # останов на первой команде
-v, --visual    # визуальный режим отладчика
-t, --trace     # трассировка экстракодов
```

## Экономия токенов

При выполнении команд:
- Не повторять уже выданный текст
- Использовать краткие формулировки
- Группировать операции
- Ссылаться на ранее показанные фрагменты

# Навык анализа трасс ОС ДИСПАК

## Формат трассы

### Нотация
```
ИР Команда адрес: Зона слово(L-левая,R-правая)
```

### Пример
```
17 100 7740: 0422 1072L
```

### Расшифровка полей
- **ИР** — Индекс-регистр (15, 16, 17 и т.д.)
- **Команда** — Код операции (8-ричный)
- **адрес** — Исполнительный адрес
- **Зона** — восьмеричный номер зоны исполняемого модуля ОС
- **слово** — смещение от начала модуля (8-ричное)
- **L/R** — половина слова (L — левая, R — правая)

### Пример расшифровки
```
ИР=17, КОМАНДА=100, АДРЕС=7740, ЗОНА=422(8)
Слово находится по адресу НАЧАЛО_МОДУЛЯ+1072₈,
L — операция относится к левой половине слова
```

## Правила анализа

### 1. Определение модуля
По номеру зоны определить модуль ОС:
- 0400-0417 — ДИСП70 (центральный резидент)
- 0420-0437 — ВЗУ
- 0440-0457 — ТЕРМ
- 0460-0477 — МОТТ
- 0500-0517 — БОЭК1
- 0520-0537 — ВИСП
- 0540-0557 — КАЧКА
- 0560-0577 — КИТ
- 0600-0617 — ДИСКИ
- 0620-0637 — ДМЛМБ

### 2. Определение операции
По коду команды определить операцию:
- `00` — СЧ (чтение)
- `01` — СЧМ (чтение модифицированное)
- `02` — ЗП (запись)
- `03` — ЗПМ (запись модифицированная)
- `04` — СЧР (чтение по регистру)
- `05` — ЗПР (запись по регистру)
- `20` — УИА (установка индекс-регистра)
- `21` — СЧИ (чтение индекс-регистра)
- `22` — УИ (установка и индекс)
- `23` — УИА (установка индекс-регистра с адресом)
- `24` — УИА (установка индекс-регистра абсолютная)
- `30` — Э30 (экстракод)
- `31-77` — другие экстракоды

### 3. Анализ переходов
- Переход на постоянную ячейку — ошибка
- Переход на пустую ячейку — ошибка
- Переход через индекс-регистр — норма

### 4. Контекст выполнения
Учитывать:
- Значения ИР до и после команды
- Режим процессора (пользовательский/супервизор)
- Активные прерывания

## Формат вывода

### Краткий формат
```
[ЗОНА:СМЕЩ] КОММЕНТАРИЙ К ОПЕРАЦИИ
```

### Полный формат
```
+------+------+------+--------+------+------------+
| ИР   | КОД  | АДР  | ЗОНА   | СМЕЩ | ОПЕРАЦИЯ   |
+------+------+------+--------+------+------------+
| 17   | 100  | 7740 | 0422   | 1072 | СЧ А(17)   |
+------+------+------+--------+------+------------+
```

## Экономия токенов

- Использовать краткий формат по умолчанию
- Полный формат только по запросу
- Не повторять расшифровку одинаковых операций
- Группировать последовательности похожих команд

# Навык анализа вывода БЭСМ-6: трассы, зоны, подвал АЦПУ

## Назначение

Анализ результатов выполнения задач ОС ДИСПАК:
1. **Трасса выполнения** — сортировка, поиск и аннотация по зонам/адресам
2. **Подвал АЦПУ** — разбор распечатки: ошибки, коды завершения, ресурсы, тайминги

Метки разрешаются по листингам `.lst` из проекта re-dispak.

## Инструменты

### 1. `trace_analyze.pl` — Perl-анализатор трассы

**Расположение:** `~/Yandex.Disk/re_dispak/re-dispak/trace_analyze.pl`

**Формат входной трассы** (touched.pl output):
```
02 50 0133: 0677 0001L
07 01 0004: 0676 1501R
```
Формат: `<команда>: <зона> <адрес>L|R`

**Вызов:**
```bash
perl trace_analyze.pl --labels-dir <path> [опции] <trace.txt>
```

**Опции:**
| Опция | Описание |
|-------|----------|
| `--labels-dir DIR` | Директория с .lst файлами |
| `--zone ZZZZ` | Фильтр по зоне |
| `--summary` | Только сводка по зонам |
| `--unique` | Сводка + уникальные адреса по зонам |
| `--sort zone\|addr\|count` | Режим сортировки |

### 2. `trace_zones.sh` — Bash-обёртка

**Расположение:** `~/Yandex.Disk/simh/BESM6/scripts/trace_zones.sh`

```bash
./scripts/trace_zones.sh /tmp/tr12.txt                    # полный анализ
./scripts/trace_zones.sh /tmp/tr12.txt --summary          # сводка
./scripts/trace_zones.sh /tmp/tr12.txt --unique           # уникальные адреса
./scripts/trace_zones.sh /tmp/tr12.txt --zone 0677        # только СВЯЗЬ7
./scripts/trace_zones.sh /tmp/tr12.txt --grep ТРМДКС      # grep по метке
./scripts/trace_zones.sh /tmp/tr12.txt --sort count       # сортировка по частоте
```

### 3. `acpu_analyze.pl` — Анализ подвала АЦПУ

**Расположение:** `~/Yandex.Disk/re_dispak/re-dispak/acpu_analyze.pl`

Разбирает «подвал» распечатки АЦПУ — блок информации ОС ДИСПАК внизу каждой страницы вывода.

**Вызов:**
```bash
perl acpu_analyze.pl <output.txt>              # полный разбор
perl acpu_analyze.pl <output.txt> --summary    # краткая сводка
perl acpu_analyze.pl <output.txt> --jobs       # только задания
perl acpu_analyze.pl <output.txt> --errors     # только ошибки
perl acpu_analyze.pl <output.txt> --resources  # только ресурсы
perl acpu_analyze.pl <output.txt> --devices    # только устройства ВУ
```

**Структура «подвала» АЦПУ:**
```
   2ОШ.ПАРАМ.АРХИВА↑ ...                    ← ошибки (опционально)
   КОНЕЦ ЗАДАЧИ   +mantissa⏨exp  hex       ← код завершения
   АП  Э  РК  И1..И17  КРА  ЗПСЧ           ← регистры процессора
   <значения регистров>
   ДАТА РЕШ. ВЕРСИЯ СМЕ НАЧ.ВВОДА ...       ← заголовок таймингов
   <значения таймингов>
   ОС ДИСПАК  ОЗУ ТРАКТЫ ВРЕМ.РЕШ. ...      ← заголовок ресурсов
   ЗАКАЗАНО: ...                             ← заказано
   ЭМУЛЯТОР  ИСПОЛЬ-НО: ...                 ← использовано
   БОБ: ...                                  ← блок обработки
   *ИМЯ*  S= XXXX  time  code               ← статус задания
   ИТМ И ВТ...                               ← учреждение
   *АЦПУ-N  ЭВМ-3  HH.MM.SS*                ← штамп времени
   ***...***  /  555...555                    ← разделитель/заполнитель
```

**Извлекаемые данные:**
- **Ошибки:** ОШ.ПАРАМ.АРХИВА, СБО, системные ошибки
- **Код завершения:** мантissa, экспонента, hex-код
- **Регистры:** АП, Э, РК, И1-И17, КРА, ЗПСЧ
- **Тайминги:** дата, версия ОС, время начала/конца, коммутационное время
- **Ресурсы:** заказано/факт — ОЗУ, тракты, время, категория, АЦПУ, ВУ, ТРВ, ПИ, ПЛ, ТЕРМ, МБ, МД, МЛ
- **Статус задания:** имя, S=, общее время, код ошибки
- **Дисководы:** номер, том, тип (ОБЩ/СИС/ИНД/АРХ), статус
- **Устройства ВВ/ВЫВ:** буфер, режим, открытые/закрытые

## Типичный сценарий анализа

```bash
perl acpu_analyze.pl ~/Yandex.Disk/simh/BESM6/ACPU/output.txt --resources
```

```bash
# Уникальные адреса в СВЯЗЬ7
./scripts/trace_zones.sh /tmp/tr12.txt --zone 0677 --unique

# Поиск конкретной метки
./scripts/trace_zones.sh /tmp/tr12.txt --grep ФИКПРП

./scripts/trace_zones.sh /tmp/tr12.txt

diff <(./scripts/trace_zones.sh /tmp/tr12_base.txt --unique 2>/dev/null) \
     <(./scripts/trace_zones.sh /tmp/tr12_test.txt --unique 2>/dev/null)
```

### Диагностика ошибок
```bash
# Ошибки в АЦПУ
perl acpu_analyze.pl output.txt --errors

# Ресурсы (выявить перерасход)
perl acpu_analyze.pl output.txt --resources

# Устройства ВУ
perl acpu_analyze.pl output.txt --devices

# Трасса: где остановился
./scripts/trace_zones.sh /tmp/tr12.txt --unique
```

## Интеграция с run_t133.sh

`run_t133.sh` — основной сценарий прогона теста Э50133. Поддерживает флаги:

| Фаза | Флаг | Описание |
|------|------|----------|
| 1. Прогон | (всегда) | Загрузка ОС, ввод теста, ожидание В0 |
| 2. Результаты | (всегда) | Сбор log.txt, debug_dks.log, анализ КАДОПАМ |
| 2.5. АЦПУ | `--acpu` | Анализ подвала АЦПУ через acpu_analyze.pl |
| 3. Трасса | `--trace` | Снятие трассы (touched.pl), анализ зон (trace_zones.sh) |
| 4. Анализ СВЯЗЬ7 | `--analyze` | analyze_link7.pl |
| 5. ДКС | `--check` | Проверка 7 точек ДКС |

```bash
# Типичный полный прогон
./scripts/run_t133.sh --acpu --trace --check

# Только АЦПУ (если тест уже прошёл)
./scripts/run_t133.sh --acpu

# Трасса + АЦПУ + grep по метке
./scripts/run_t133.sh --trace --acpu --grep ТРМДКС
```

## Структура распечатки АЦПУ

Файл `~/Yandex.Disk/simh/BESM6/ACPU/output.txt` содержит повторяющиеся страницы.
Каждая страница = пользовательский вывод + подвал ОС ДИСПАК.

**Пример содержимого страницы:**
```
  [пользовательский вывод программы]

 2ОШ.ПАРАМ.АРХИВА↑ 2СМЕНИ ВЕРСИЮ АРХ↑ ...     ← ошибки
  КОНЕЦ ЗАДАЧИ        +271053451650⏨-19  ...   ← код завершения
   АП   Э     РК    И1    И2   ...   КРА  ЗПСЧ
 75742 75742 00007 76523 40000 ...   76605 00000
  ДАТА РЕШ.  ВЕРСИЯ 117 СМЕ  НАЧ.ВВОДА  ...
   17.09.09   06.12.88   1    14.50.52  ...
   ОС ДИСПАК              ОЗУ ТРАКТЫ ВРЕМ.РЕШ.  ...
                         ЗАКАЗАНО:  0018   000   09.59.59
   ЭМУЛЯТОР             ИСПОЛЬ-НО:  0007   000   00.00.00
   БОБ:СИСТ :40(07) ...
   0   *ОС ДИСПАК*  S= 0000          000.00.00   0480
                                                 *АЦПУ-0  ЭВМ-3  14.51.00*
  ********************************************************************************************************************************
  5555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555555
```

**Границы подвала:**
- Начало: строка `КОНЕЦ ЗАДАЧИ` или `СБО`
- Конец: строка `555...555` (заполнитель страницы) или `***...***` (разделитель)

## Правила

1. Листинги `.lst` должны находиться в `~/Yandex.Disk/re_dispak/re-dispak/`
2. Трасса формируется `touched.pl` из dump-файлов ОС ДИСПАК
3. Метки `???` означают адрес внутри модуля, не являющийся точкой входа
4. Зоны помимо 0676/0677 не имеют листингов — адреса остаются числовыми
5. Для добавления новой зоны — отредактировать `%ZONE_MODULE` в `trace_analyze.pl`
6. Подвал АЦПУ появляется только если ОС ДИСПАК печатает распечатку
7. Если `output.txt` пуст — тест не дошёл до печати или нет разрешения на АЦПУ

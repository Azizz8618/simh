# Навык контекстного сжатия C-файлов (code-map)

## Назначение

Полные C-файлы эмулятора БЭСМ-6 (besm6_cpu.c = 2105 строк ≈ 27k токенов)
читать целиком для навигации расточительно. Навигационная карта (~150 строк
≈ 2k токенов) заменяет полное чтение в 13 раз, оставляя полное чтение только
для точечного редактирования конкретного региона.

## Каталог карт

Карты хранятся в `.cline/maps/<имя_файла>.map`:
- `besm6_cpu.c.map`
- `besm6_tty.c.map`
- `besm6_mmu.c.map`
- `besm6_disk.c.map`
- `besm6_defs.h.map`

## Когда использовать карту (АВТОМАТИЧЕСКИ)

Карта используется ВСЕГДА при обращении к файлам из LARGE_FILES — это
правило M1/M6 в .clinerules, применяется автоматически без триггеров.

| Ситуация | Действие |
|----------|---------|
| Найти функцию/переменную | Читать `.map` (~2k токенов) — НЕ полный файл |
| Понять структуру файла | Читать `.map` |
| Редактировать конкретный регион | Читать `.map` → затем full read с start_line/end_line |
| Добавить новую функцию в конец | Читать `.map` (для контекста) → editor с insert_line |
| Поиск по содержимому | `grep -n` (не карту и не полный файл) |

## Правила свежести карты

Перед использованием проверить актуальность:
```bash
test <исходник> -nt .cline/maps/<исходник>.map && echo "КАРТА УСТАРЕЛА"
```
Если карта устарела (исходник новее) — регенерировать скриптом (см. ниже).

## Автоматическая регенерация карты

Карты генерируются скриптом `scripts/gen_code_map.sh` (awk-парсер `scripts/gen_map.awk`):
```bash
# Одна карта (регенерировать):
./scripts/gen_code_map.sh besm6_cpu.c

# Проверить и обновить только устаревшие:
./scripts/gen_code_map.sh --check

# Обновить одну карту если устарела:
./scripts/gen_code_map.sh --check besm6_cpu.c

# Регенерировать все карты:
./scripts/gen_code_map.sh --all
```
Скрипт извлекает: функции (с диапазонами строк), глобальные переменные,
#define-константы, typedef/struct — автоматически из исходного кода.
Назначение функции берётся из комментария над её определением.

## Формат карты

```
=== <имя_файла> — <N> строк ===
Источник: <имя_файла> | Регенерировать: test <файл> -nt .cline/maps/<файл>.map

=== ГЛОБАЛЬНЫЕ ПЕРЕМЕННЫЕ ===
| Имя | Тип | Стр | Назначение |
|-----|-----|-----|------------|
| memory[] | t_value | 58 | Образ оперативной памяти |
| PC,RK,Aex | uint32 | 59 | Регистры процессора |

=== КЛЮЧЕВЫЕ КОНСТАНТЫ / #define ===
| Имя | Значение | Стр | Назначение |
|-----|----------|-----|------------|
| MEMSIZE | 512K | 45 | Размер ОП в словах |
| PRP_DKS_SREQ | 000004000 | 501 | ПРП12 — запрос S-терминала |

=== ФУНКЦИИ ===
| Имя | Строки | Назначение |
|-----|--------|------------|
| cpu_examine | 325-345 | Чтение ячейки (отладка simh) |
| write_032 | 971-1019 | Запись в КАДОПАМ (команда 132) |
| read_032 | 1021-1049 | Чтение из КАДОПАМ (команда 032) |
| cpu_one_inst | 1051-1783 | Выполнение одной инструкции |
| sim_instr | 1825-2041 | Главный цикл эмуляции |

=== СТРУКТУРЫ / TYPEDEF ===
| Имя | Стр | Поля |
|-----|-----|------|
| dks_term_t | 198-202 | unit, base_addr, active |
```

## Экономия токенов

| Файл | Полное чтение | Карта | Сжатие |
|------|---------------|------|--------|
| besm6_cpu.c | ~27k ток | ~2k ток | 13× |
| besm6_tty.c | ~22k ток | ~1.8k ток | 12× |
| besm6_mmu.c | ~10k ток | ~1k ток | 10× |
| besm6_disk.c | ~13k ток | ~1.2k ток | 11× |
| besm6_defs.h | ~6.5k ток | ~1k ток | 7× |

## Интеграция с .clinerules

Раздел `## === КАРТЫ КОДА (CONTEXT COMPRESSION) ===` в .clinerules содержит
правила M1-M6. Карты входят в кешируемый префикс (раздел PROMPT CACHING).

## Применение (АВТОМАТИЧЕСКИ)

Сжатие контекста применяется автоматически — без активации навыка:

1. **Старт сессии**: `./scripts/gen_code_map.sh --check` — актуализация карт (M5)
2. **Обращение к LARGE_FILES**: читать `.map` вместо полного файла (M1/M6)
3. **Навигация**: найти символ в `.map` → полное чтение только нужного диапазона (M2)
4. **После правки**: повторно `--check <file>` для актуализации карты (M6.3)

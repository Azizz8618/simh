# Чек-лист перед отправкой сложного запроса (анти-таймаут)

Назначение: предотвратить ошибку провайдера
«The model did not respond in time» — проверять запрос ДО отправки.

## Чек-лист

- [ ] Запрос требует > 4 инструментальных вызовов? → разбить на 2-3 запроса
- [ ] Ожидаемая правка > 100 строк? → разбить на части
- [ ] Контекст сессии > 60k токенов (долгая отладка)? → `/newtask`
- [ ] Есть готовая карта `.cline/maps/<файл>.map`? → читать карту, не файл
- [ ] Логи/состояние эмулятора? → командой (`tail -50 debug.txt`), не вставкой

## Шаблон дробления сложной задачи

```
Ход 1: «Проанализируй X, ничего не меняй, дай краткий вывод»
Ход 2: «Составь план из N шагов, каждый ≤ 4 вызовов»
Ход 3: «Выполни только пункт 1, остановись, покажи diff»
Ход 4+: «Выполни пункт 2» ... (по одному)
После вехи (сборка прошла): /newtask
```

## Ответы на вопросы

### 1. Возврат после ФИЗОБМ и вход в ДУДКУ
нерез (trubka.be:703-714): уии М11(М16); пб ФИЗОБМ — читает зону 0576 в
лист. Возврат — по М11 (адрес возврата, сохранён в М11 перед ФИЗОБМ).
Механизм передачи управления в загруженный модуль: трб7яч (зп трб7яч в
нерез, trubka.be:708) — МЁРТВЫЙ код (trubka.be:718-721); фактически
управление возвращается в гпнити после нафиз, а старт ДУДКА происходит
через штатный контекст нерезидента (БНСО сохранён в нерез: счи М16;
зп БНСО, trubka.be:705). ДУДКА стартует от своей точки входа в загруженном
листе (мод БНСО; уиа 0(М16), dudka.be:54-59), М16 := БНСО.

### 2. Данные кадра — выводной поток
Данные идут через выводной поток задачи: выводная информация попадает в
зоны вывода на информационном МБ (НОММБ), каталог вывода — зона 0550
системного МД (КУСВЫВ п'01И200' disp70.be:827, КУС550 dnepr.be:1809,
sysprog-guide.md:171). Именно их читает вдудку (benson.be:133-149) через
ФИЗОБМ по КУС из 2-го слова ИПЗ (КУС = м17в'1'м2в'24', benson.be:25).
Разгрузка выходного потока — ЭК 062 42В (programmer-guide.md:5121).
ЭК 0120/0121 — пароли МД/МЛ (rukava.be:3001), к выводу отношения не
имеют; Э73 — ввод, не вывод.

### 3. Прерывание 18Р (ЗАМЕНА-обработчик)
Подмена вектора: сч обвнп1+30; зп СТАРОЕ; сч ЗАМЕНА; рег '101';
зп обвнп1+30 (dudka.be:120-131). Обработчик (dudka.be:242-294): на
каждом 18Р — рег '34' ×6 слов (0, D10167, 0, е28е25, 0, D10171) и
рег '240' (чтение слова на сумматор, dudka.be:265), продвижение
счётчиков D10155/D10156 (фазы 0/1 — 2 прерывания на слово), D10114
(признак продолжения).

### 4. Формат данных
печшк3 (benson.be) раскладывает слова на 16-разрядные элементы (маски
е16п1=0177777, D10310=017777, D10115=060000, D10114=01377) в кольцевой
буфер ячсост (0330-0377). Соответствие кодам 6501/6502/6511/6514 НЕ
расшифровано (docs/BENSON-COMMAND-FORMAT.md: «Не найдено»). Кадр =
страница 1024 слова; конец — D10114 = 0.

### 5. Как задача передаёт кадр
Штатный путь — выводной поток (зоны МБ). ЭК 50 1211 в гостевой ТРУБКЕ
ОТСУТСТВУЕТ (grep по trubka.be/disp70.be/vzu.be пуст; ЭК1201→Э1240 и
ГРАИТМ — заглушки НОП, trubka.be:365-366; типтрм лишь помечает лист).
64-словный буфер ГРАФАЛ (trubka.be:398-425) — калкомповский тракт
(РЕГ 29 в КОБГР, boek1.be:2209), не путь 1216. «ВЫВ ГП 36» — такого
паспортного раздела нет (проверен список 3.2.2 programmer-guide.md).

### 6. Завершение
Штатный конец: бит 48 во 2-м слове ИПЗ (конец выводного потока,
dudka.be:192-194) → G10072 (199-212): счётчик кадров в 0-е слово ИПЗ,
ТВ67А (гашение маски 18Р), рег '34' ×2 (сброс), возврат листа D10161
ТБУФ с битом E19; ВЫХОД (214-228): возврат D10162, восстановление
вектора обвнп1+30 из СТАРОЕ, очистка БРЗ, рег '107'.
18Р: по 2 на слово (фазы D10156 0/1), на страницу 1024 слова ≈ 2048
прерываний (docs/GRP18-INTERRUPT-FLOW.md §4.2).
Если 18Р не придёт: сч D10114; по G10054 — бесконечный повтор вдудку,
задача не завершится. Таймаутов в ДУДКЕ нет (в отличие от ТРУБКИ,
будильник 3777, trubka.be:138-139).

## Не найдено / оговорки
1. Команда выбора слота +01000 внутри зонной группы 0576 — в живом коде
   не найдена (трб7яч — мёртвый код, trubka.be:718-721).
2. Смысл D10167/D10171 помечен в исходнике как предположительный
   (dudka.be:324-341).
3. 16-битные элементы печшк3 ↔ коды 6501/6502/6511/6514 не расшифрованы.
4. «ВЫВ ГП 36» — паспортного раздела нет.
5. ЭК 50 1211 в гостевой ТРУБКЕ отсутствует; путь 1211→зоны МБ есть
   только в пакетном эмуляторе dispak (extra.c).

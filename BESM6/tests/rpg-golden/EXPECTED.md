# Эталонные значения теста РПГ

Исторический протокол РПГ не восстановлен полностью. Цвета 1..6 и ширина
рулона 68 см взяты из `gp1.be`/`gp4.be` (репозиторий `re-dispak`), кодировка
кадров УК описана в `doc/ГП.md`. Байты УК подаются только через канал ПЛ
`0170/0171`; это не БЕНСОН и не `ЭК 1210/1211`. Дополнительный бит пера
для цветов 4..6 и имена цветов SVG - гипотеза модели, не исторический факт.

`rpg-line.svg` и `rpg-color.svg` в этом каталоге - побайтовые эталоны выдачи
модели РПГ в simh. Они получены прогонами `run-rpg.py` и совпадают с расчётной
геометрией из массивов X/Y/P/DX/DY соответствующих дек.

Формат строк, которые читает `run-rpg.py`:

```
mode line: sha=566e8034467a72d76c7ea02ec4b9c6e833e55e007b6ac08b9cc0c1e35d426ac3 size=478 paths=3 colors=2
mode color: sha=0b562ed387095c96db5472cadba7780d3eee0318b8af0ba4e6199c8583ba2853 size=714 paths=6 colors=6
```

Эти SHA получены прогоном модели через тестовый хук `set pl1 rpg-uk`
с той же последовательностью УК, что и у раннера, и совпадают с
расчётными геометрическими эталонами. Полный прогон через ПЛ подтверждён
`run-rpg.py`: три прогона цветного режима дали побайтово одинаковый SVG.

| Режим | Источник | Path | Цвета | Ширина SVG |
|---|---|---:|---|---|
| line | `../rpg-line.b6` | 3 | black, red | `340mm` |
| color | `../rpg-color.b6`, `rpg-wide`, `rpg-6color` | 6 | black, red, green, blue, magenta, cyan | `680mm` |

Эталонные файлы выдачи симулятора:

| Файл | Размер | SHA256 |
|---|---:|---|
| `rpg-line.svg` | 478 | `566e8034467a72d76c7ea02ec4b9c6e833e55e007b6ac08b9cc0c1e35d426ac3` |
| `rpg-color.svg` | 714 | `0b562ed387095c96db5472cadba7780d3eee0318b8af0ba4e6199c8583ba2853` |

Шаг по умолчанию в раннере: `rpg-step=0.125` (0,125 мм, `СМ` из `gp1.be`).
Переопределяется переменной `RPG_STEP`; модель принимает также `0.0625`,
`125` и `625`.

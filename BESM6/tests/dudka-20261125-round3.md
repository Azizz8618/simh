# СТАТУС: Э50 1216 + ДУДКА + ГП по схеме НИТИ — раунд 3 (25.11.2026)

## ГЛАВНАЯ НАХОДКА РАУНДА: системный МБ (барабаны) пуст — вся цепочка грузит нули

Цепочка ЭК 50 1216 → ВЗУ → ТВ40 → ВИСП → ФИЗОБМ читает нерезидент ТРУБКА
(зона «43»0413) **с системного МБ** (rvs.src: `мдл трубка43zzzz^наз
010000^зонгп 430413`). В текущей песочнице барабаны drum0/drum1 создаются
НУЛЕВЫМИ (старые образы ~/Yandex.Disk/.../drum1x.bin, drum2x.bin потеряны
при рецикле) → ВИСП «загружает» 1024 нулевых слова как ТРУБКА → модуль =
нули → всё «молча» возвращается. Это объясняет ВСЕ затыки (раунды 2-3):
- t16 (ЭК 1216+ключ): 0413 читается из нулей → тихий выход, КЗ штатно;
- регрессии gp-star/irq/fig: вообще не бутятся — ОС требует МБ при старте;
- фаза A/B2 ранее: «ТРУБКА загружена» была ложным диагнозом (нули).

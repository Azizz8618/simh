# Эталонная выдача gp-fig

Получена прогоном `run-gp-fig.py` в simh с бинарником, содержащим
`set gp testirq`. Исходная программа: `../gp-fig.f77`, карточная дека с
встроенным `PDEV`: `../gp-fig-deck.b6`, гостевой обработчик: `../gp-fig-handler.b6`.

Фигура: замкнутый восьмиугольник с обрамляющим прямоугольником.
14 кадров по 64 слова, координаты в шагах 0.1 мм, диапазон X=500..4500,
Y=500..7000. Первый кадр имеет перо поднятое, поэтому SVG содержит
13 штрихов.

| Файл | Размер | SHA256 |
|---|---:|---|
| `plot.dat` | 22400 | `ba6c96fb7330c6800d10d738c95e19811a79ccbf939281fc1ef6d0fb29727a77` |
| `benson.out` | 2650772 | `56948a801159cbe93891820650df7d840004fd1830443e663cf30bdc028e72a0` |
| `benson.svg` | 849 | `c39af7ec38766a5df151936071edf14ab4ae3b01f486af1ab184f703537e7e55` |

Геометрия SVG: `width=4502`, `height=7001`, `<path>` = 13.
Три последовательных прогона дали побайтово одинаковые файлы.

Команды БЕНСОНа в `benson.out` помечены `[аналог NASA, БЕНСОН-501]`,
это не подлинный протокол НИТИ/БЭСМ-6.

# TEAM_AGENTS.md — Координация агентов для проекта БЭСМ-6/Диспак

## Роли агентов

| Агент | Проект | Ответственность |
|-------|--------|-----------------|
| `emulator` | simh/BESM6 | Код эмулятора: besm6_tty.c, besm6_cpu.c, ДКС |
| `os-analyst` | re_dispak/re-dispak | ОС Диспак: модули, трассы, СВЯЗЬ7 |

## Типичные задачи

### emulator
- Реализация команд 032/132 (КАДОПАМ)
- Генерация прерываний ПРП5-8,12
- Регистрация DKS-терминалов
- Отладка kadopam_svc()

### os-analyst
- Проверка загрузки СВЯЗЬ7 (зона 0677)
- Анализ реакций на ПРП (процедуры H-терминала)
- Трассировка обмена через ДКС
- Комментарии к модулям ОС

## Координация

1. **Проблема**: ОС не реагирует на прерывания ДКС
   - `emulator`: проверить маски MGRP/MPRP, генерацию ПРП
   - `os-analyst`: проверить загруженность СВЯЗЬ7, вектора прерываний

2. **Проблема**: Терминал не получает эхо
   - `emulator`: проверить dks_poll(), запись в kadopam_mem
   - `os-analyst`: проанализировать трассу МОТТ, буферы H-машины

## Команды для агентов

Стандартные команды из re-dispak/AGENTS.md:
- «ПРОКОММЕНТИРУЙ ФАЙЛ»
- «ОБЪЯСНИ [ПРОЦЕДУРУ]»
- «ПРОАНАЛИЗИРУЙ ТРАССУ»
- «ИСПРАВЬ [КОММЕНТАРИЙ/УЧАСТОК]»

Для эмулятора добавить:
- «ПРОВЕРЬ ПРЕРЫВАНИЕ ПРП[N]»
- «ПРОВЕРЬ МАСКИ MGRP/MPRP»
